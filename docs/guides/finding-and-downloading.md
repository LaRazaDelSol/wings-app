# Finding and downloading a game

## Find it

- **Browse.** Store shows one tile per game. The same game from several sources is one tile.
- **Search.** Triangle opens the search box. Type with the on-screen keyboard or slide the touchpad over the keys and click. Results update as you type. The box matches title, title ID, source or tag. Recent searches show as chips under the field.
- **Filter and sort.** The sort and filter button in the grid header offers sorts (including most popular and highest rated when [popularity data](popularity-and-privacy.md) is on) and grid filters (region, firmware fit, format, host, source, single file only, no browser needed). A filter only appears when it has something to choose between. When nothing matches, Cross resets the filters.
- **Favourites.** Square on a tile.

## Open the page

Cross on a tile. The page groups what is available into **Base**, **Update** and **DLC**, then by release (version). Each mirror is a card. The **Best** card is the one Wings would pick for you and says why; see [Link types and what Best means](link-types.md).

On the page, Options opens **Filters** (region, format, host, source, firmware fit, single file, no browser needed) and the sort of mirrors inside a release (Best, newest, fewest parts, host).

## Download

- **One link:** Cross on a card. Wings asks Pegasus to queue it and tells you what it did. Watch it in **Downloads**.
- **A multi-part set:** the card says "parts 1-22" and warns when numbers are missing. Cross on it says **Choose parts**, where you can pick parts or **Download all parts**. Download all parts asks first, queues the parts one at a time and can be stopped with Circle after the part in flight. A host that needs a browser check makes each part need its own capture; Wings says so before it starts.
- **Browser capture:** some hosts need a check in the PS5 browser. Pegasus handles the capture; Wings shows the state.

After a download, Pegasus merges, extracts and (for `.pkg`) can install it. If an archive asks for a password or holds more than one package, the job waits for you: see [Archive passwords](archive-passwords.md).

## Where things go

Pegasus decides the download folder (Settings, **Pegasus DL** group, "Download folder"). Use [Files](files-tab.md) to move or extract them.
